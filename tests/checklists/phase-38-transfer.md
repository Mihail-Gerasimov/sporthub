# Реестр переноса главной — фаза 38

**Зачем этот файл.** Ни один элемент не переносится по памяти. Одна строка — один
элемент старого экрана, и у каждого обязателен исход. Пустых исходов быть не может:
пропущенная строка — это молча потерянный функционал.

**Исходы, всего пять:**

| Исход           | Что означает                                                  |
| --------------- | ------------------------------------------------------------- |
| `ПЕРЕНОСИМ ВИД` | поведение верное, меняется только внешность                   |
| `ДОРАБОТАТЬ`    | в дизайне поведение есть, у нас нет — пишем                   |
| `НАШЕ СИЛЬНЕЕ`  | у нас работает, в дизайне заглушка или тупик — оставляем своё |
| `ВЫКИНУТЬ`      | ведёт в разделы вне фазы                                      |
| `ПОЧИНИТЬ`      | наш собственный тупик — даём цель или снимаем                 |

⚠️ **Сторож `testid-registry`** (шаг 38.13a) сверял три вида контрактов приложения А —
`data-testid`, data-атрибуты и подписи — с кодом по области и держал реестр честным по ходу
переноса. **На 38.103 сторож снимается вместе с фазой: реестр остаётся документом** —
записью того, что и куда перенесено, а не живым контрактом. Исчезнувший контракт назван
здесь со статусом и причиной; после 38.103 за это отвечает не сторож, а следующая фаза,
которая тронет главную.

⚠️ **Довесок Э13 (38.111): пометки «Э13, факт» — по коммитам, не по плану.** Семнадцать
строк с пометкой «Э13» (шапка 5–7, док 25–28, чип города 32, лента 37, карточки 85/88/89/93
и 100/105–107) и строки 77/81 слайдера дописаны по коду довеска: герой `09c0754`, карточки
`d5e08fe`/`db88bc3` (ревью `707f81f`, `182b0a3`), витрина `2aa58fa`/`de1180c`, навигация
`3d15a64`/`ae38aa0`/`9c8d4e6`. Заголовки витрины в HEAD — **без города** (О-2, `de1180c`),
хотя `71882f5` город добавлял: записан последний факт.

⚠️ **Честно про сторож до его снятия (38.98):** подписи и data-атрибуты он ищет по тексту
файлов **включая комментарии** — снятые подписи «Лидеры каталога» и «Определить район»
не красили его, пока упоминались в пояснениях кода. Поэтому статус снятых подписей
в приложении А — по коммиту (`d686a53`, `b412f36`), не по зелёному сторожу.

⚠️ **Реестр правится вместе с кодом**, а не после. Устаревший реестр хуже отсутствующего:
он отчитывается о переносе, которого не было.

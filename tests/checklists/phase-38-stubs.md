# Реестр заглушек — фаза 38

**Правило.** Каждая заглушка в коде помечена `STUB:` и записана здесь; каждая
запись здесь указывает на живую пометку. Сторож `stub-registry` красен в обе стороны:
(а) `TODO` / `FIXME` / `HACK` без `STUB:` или файл с `STUB:` без записи;
(б) запись, в файле которой пометки уже нет, — «запись без предмета».

⚠️ Одна строка — один файл: сторож сверяет по пути. Несколько пометок в одном
файле, относящихся к одной заглушке, — одна строка.

## Как добавить заглушку

1. В коде — комментарий, начинающийся с `STUB:`, на русском: что заглушено и чем
   заменяется.
2. Строка в таблице выше: путь в обратных кавычках, предмет, замена, срок.
3. Заглушки фото витрины (шаг 38.94) записываются сюда же.

в таблице сверки путь стоит второй ячейкой. Проверено на месте: первая редакция этой

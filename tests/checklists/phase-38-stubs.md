# Реестр заглушек — фаза 38

**Правило.** Каждая заглушка в коде помечена `STUB:` и записана здесь; каждая
запись здесь указывает на живую пометку. Сторож `stub-registry` красен в обе стороны:
(а) `TODO` / `FIXME` / `HACK` без `STUB:` или файл с `STUB:` без записи;
(б) запись, в файле которой пометки уже нет, — «запись без предмета».

⚠️ Одна строка — один файл: сторож сверяет по пути. Несколько пометок в одном
файле, относящихся к одной заглушке, — одна строка.

| Файл                                                      | Предмет                                                               | Чем заменяется                                                                     | Когда          |
| --------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | -------------- |
| `apps/web/src/components/profile/athlete-achievements.ts` | streak без отмен считается по hard-delete данным и обычно даёт 0      | переход к soft-delete либо явный lifecycle completed/cancelled                     | долг, вне фазы |
| `apps/api/prisma/schema.prisma`                           | переходная колонка `Trainer.sportId` «основной вид спорта» из фазы 25 | `primarySportId` и новая выдача; поле есть в эталоне контрактов — только вычислять | долг, вне фазы |
| `apps/api/src/repositories/prisma/entities.repository.ts` | запись и чтение той же переходной колонки `sportId`                   | вместе со схемой                                                                   | долг, вне фазы |
| `packages/types/src/types.ts`                             | поле `Trainer.sportId` в контракте — переходная совместимость         | `primarySportId`                                                                   | долг, вне фазы |

## Как добавить заглушку

1. В коде — комментарий, начинающийся с `STUB:`, на русском: что заглушено и чем
   заменяется.
2. Строка в таблице выше: путь в обратных кавычках, предмет, замена, срок.
3. Заглушки фото витрины (шаг 38.94) записываются сюда же.

# Диверсии фазы 34

**Что это.** Проверка самих проверок. Ломаем код — тест обязан покраснеть. Если не краснеет,
тест ничего не проверяет, и зелёный прогон ничего не значит.

**Как гонять.** Каждая строка: внести поломку, прогнать указанный тест, убедиться в красноте,
вернуть код (`git checkout -- <файл>`), убедиться в зелени. Поломка **никогда** не коммитится.

**Правило прогона тестов на базе** (иначе прогоны затирают схемы друг друга):

```bash
cd apps/api && SPORTHUB_TEST_SCHEMA_SUFFIX=div npx vitest run <файл>
```

⚠️ **Особенность этой фазы.** Часть диверсий проверяет не «сломается ли», а «заметим ли, что
сломалось». Диверсия d-1 — главная: она вскрывает ложную зелень сторожа паролей, которая
и была найдена при планировании фазы.

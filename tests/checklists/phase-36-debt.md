# E2E: Phase 36 — закрытие долга

**Base URL:** http://localhost:3000
**Preconditions:** `npm run app:up`, база мигрирована, свой `E2E_RUN_TAG`
**Инструмент:** Playwright MCP по правилам `.claude/skills/e2e-playwright/SKILL.md`
**Изоляция данных:** `scripts/e2e-fixture.mjs` — прогон заводит своих людей и убирает
за собой, в том числе после падения

> **Зачем этот чек-лист именно такой.** Всё, что можно спросить у маршрута, уже спрошено
> тестами. Здесь проверяется только то, чего API не покажет: **доходит ли правило
> до браузера**. Главный вывод фазы 35 — пока проверка смотрит на API, целый класс
> дефектов невидим.

---

## Scenario 1: правка публикации не трогает расписание

- [ ] **step-1** Вход владельцем клуба через `POST /api/auth/login`, затем `browser_navigate`
- [ ] **step-2** Запомнить расписание клуба и число записей на нём (через `GET /api/clubs/:id`)
- [ ] **step-3** Открыть форму правки клуба, изменить **только телефон**, сохранить
- [ ] **step-4** Assert: расписание совпадает со снятым в step-2 **до слота**
- [ ] **step-5** Assert: число записей не изменилось, ни одна не в статусе отмены
- [ ] **step-6** Открыть форму, удалить слот, **на котором есть будущая запись**, сохранить
- [ ] **step-7** Assert: отказ с числом записей, слот остался, запись жива
- [ ] **step-8** Отменить запись, повторить удаление слота — теперь проходит

## Scenario 2: скрытая публикация и три смотрящих

- [ ] **step-9** Модератором скрыть публикацию с причиной
- [ ] **step-10** Гостем (чистый контекст) открыть карточку по прямой ссылке — expect «не найдено»
- [ ] **step-11** Гостем: `GET /api/clubs?includeHidden=true` через `browser_evaluate` — expect отказ
- [ ] **step-12** Гостем: публикации нет ни в каталоге, ни в расписании, ни в списке тренеров клуба
- [ ] **step-13** Владельцем открыть свою скрытую — expect карточка **с плашкой и причиной**
- [ ] **step-14** Модератором открыть её же — expect карточка целиком
- [ ] **step-15** Гостем попытаться записаться на слот скрытой публикации — expect отказ

## Scenario 3: архив владельца — не скрытие модератором

- [ ] **step-16** Владельцем убрать свою публикацию в архив
- [ ] **step-17** Открыть её в кабинете — expect плашка **не** содержит «скрыто модератором»
      и не показывает причину модерации
- [ ] **step-18** Модератором открыть раздел модерации — expect архив владельца **не**
      значится ожидающим проверки

## Scenario 4: правка скрытой уходит на повторную проверку

- [ ] **step-19** Модератором скрыть публикацию, владельцем исправить и сохранить
- [ ] **step-20** Assert: публикация **осталась скрытой**, в каталоге её нет
- [ ] **step-21** Assert: в разделе модерации у неё признак «исправлено, ждёт проверки»
- [ ] **step-22** Войти администратором, открыть колокольчик — expect уведомление
      «владелец исправил»
- [ ] **step-23** Модератором снять скрытие — публикация возвращается в каталог

## Scenario 5: скрытие при живых записях

- [ ] **step-24** Завести запись на публикацию, модератором попытаться её скрыть
- [ ] **step-25** Assert: отказ с числом записей, публикация в каталоге
- [ ] **step-26** Отменить запись, повторить — скрытие проходит

## Scenario 6: мусорная cookie

- [ ] **step-27** Поставить `sh-session=never-issued-value`, открыть `/profile/me`
      — expect увод на главную
- [ ] **step-28** Assert: размер ответа сопоставим с ответом гостю без cookie (замер `curl`)
- [ ] **step-29** С той же мусорной cookie открыть `/service-portal` — expect **страница
      входа открылась** (иначе человек заперт вне входа)
- [ ] **step-30** Assert: cookie погашена — повторный заход не платит рендером снова

## Scenario 7: первое лицо заводится из личного кабинета

- [ ] **step-31** Зарегистрировать нового человека, войти
- [ ] **step-32** Открыть `/profile/me` — expect кнопки «Опубликовать клуб» и
      «Опубликовать карточку тренера»
- [ ] **step-33** Завести клуб до конца — expect кабинет лица открылся
- [ ] **step-34** Из личного кабинета завести карточку тренера — expect **в модалке виден
      выбор клуба-площадки** (проверка ловушки 18)
- [ ] **step-35** Assert: в кабинете лица кнопок заведения больше нет

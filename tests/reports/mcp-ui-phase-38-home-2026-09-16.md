## Замечания (не дефекты образа `f2c467f`, но в работу)

1. **LOW (a11y) — `/catalog`, «Свободно» 3.21:1.** Подпись состояния на карточке слота
   ниже AA (4.5). На главной ниже AA только логотип «ПРО» 1.78:1 (лайм на белом — выбор
   макета, известно). База до покраски: 137 из 253 — ухудшения нет.
2. **LOW (фикстура) — `logoutSeedSessions` не видит сессий MCP-прогона.** Метка
   `SESSION_ID_AT_START` берётся при загрузке модуля; в MCP фикстура грузится только на
   уборке, и десять сессий `admin@sporthub.local`, заведённых входами этого прогона
   (id 41191–41209, 16:50–16:57Z), уборка не сняла. Снять их вручную не удалось —
   действие отклонено разрешениями среды; **56 сессий заказчика не тронуты**. Решение:
   метка через окружение (`E2E_SESSIONS_SINCE`) или снятие по времени прогона — на
   усмотрение координатора.
3. **LOW (UX, наблюдение) — «Профиль» в доке гостю.** Пункт ведёт на
   `/profile/me/dashboard`, откуда гостя молча уводит на `/` — без подсказки входа
   (у слота, для сравнения, тост есть). По Э13 док меняется (38.108) — проверить после.
4. Заголовки витрины сейчас «Топовые залы по рейтингу» / «Лучшие тренеры по рейтингу»;
   38.111 запишет их как «… — {город}» — после пересборки сверить с реестром.

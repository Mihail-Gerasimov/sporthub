# MCP-прогон интерфейса: проверка правок 37.72 и 37.75 на живом коде

**Дата:** 2026-09-13
**Чем прогнано:** Playwright MCP — живой браузер и дерево доступности
**Итог:** ✅ все пять проверок подтверждены, новых дефектов не найдено

## Зачем этот прогон

MCP-прогон 12.09 нашёл четыре дефекта дерева доступности и текстов, которые не увидел
ни один из 2800 тестов. Правки шага 37.72 закрыли их — но легли в ветку **после** сборки
стенда, и до сегодняшнего дня их не проверял ни браузер, ни MCP. То же и с правкой 37.75.

Прогон сделан на **пересобранном** стенде (см. `phase-37-browser-2026-09-13.md`).

## Что подтверждено

| # | Правка | Что видно в дереве доступности |

| 1 | 37.72 — подпись колокольчика несёт число | `button "Уведомления, непрочитанных: 3"`; у человека без непрочитанных — `button "Уведомления"` без числа |
| 2 | 37.72 — кнопки «Разобрать» различимы для диктора | три подряд: `"Разобрать: Работа от чужого лица"`, `"Разобрать: Администратор сменил чужой пароль"`, `"Разобрать: Вход заблокирован после подбора пароля"` |

Пункт меню тоже назван для диктора: `link "Надзор Не разобрано в очереди надзора: 3"` —
на экране это просто цифра рядом со словом.

## Чего этот прогон НЕ доказал

- **Проверялась только очередь надзора и настройки человека.** Остальные разделы панели
  и кабинета этим прогоном не обходились — для них действует прошлый отчёт.
- **Карта в этом окружении по-прежнему не грузится** (`Ошибка загрузки карты`) — это
  блокировка клиента, а не дефект приложения; проверки карты остаются непокрытыми MCP.
- **Три строки очереди заведены прогоном напрямую в базу** и убраны после проверки.
  Это значит, что подтверждена ОТРИСОВКА строк, а не путь их порождения — порождение
  проверяет браузерный чек-лист.

## Что изменилось с прошлого MCP-прогона

Четвёртая правка 37.72 — подпись настроек — прошлым отчётом была помечена как
**не закрытая тестом**: её подтверждал только живой экран. Теперь она закрыта тестом
`apps/web/src/test/profile/user-notification-preferences-editor.test.tsx` (шаг 37.79):
тест собирает переключатели, отрисованные заблокированными, и требует, чтобы подпись
называла каждый из них. Пятый такой тип покраснит первую половину, правка подписи — вторую.

Диверсия проверена: подпись, забывшая про решения по публикации, даёт
`подпись не называет «решения по вашей публикации» (тип publication_hidden_for_owner)`.

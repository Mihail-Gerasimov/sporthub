## Падения прогона — не продукта — и чему они научили

- **`innerText` применяет `text-transform`.** Три раза подряд: «КЛУБ ПРОВЕРЕН» (знак),
  «0 КЛУБОВ В ВЫДАЧЕ» (бейдж), «ПРО». Регистрозависимая проверка молчит, а её отрицание
  («знак у гостя исчез») зеленело бы ложно. Правило прогона: подписи — по `textContent`
  либо `/…/i`.
- **Переход на тот же путь с другим `#…` — переход внутри документа.** `goto('/catalog#results')`
  со страницы `/catalog#results` страницу не перезапрашивает: карточка после verify
  показывалась без знака (проход 1, step-63/64). Открытие страниц — через `about:blank`.
- **`pending`-запись за час до начала система отменяет сама** (`autoCancelHoursBeforeStart: 1`):
  отмена человеком в step-26 отбивалась 409 «cancelled_by_provider → cancelled_by_athlete».
  Данные прогона — подтверждённая владельцем запись. Правило дисциплины сработало верно.
- **Общий селектор с `.first()` берёт первое в DOM**, а не «то, что имелось в виду»:
  `#club-list, #catalog, #results` возвращал карту. Локатор — по одному `id`.
- **Капли соседних клубов перекрываются** (кластеризации нет — в долг координатором):
  клик по нижней ждёт 10 с; прогон бьёт по верхней.
- **Сторож «уезжает за край» без учёта обрезающих предков** ловил ленту видов героя.
- **Стенд подменили посреди промежуточного захода** (пересборка из грязного дерева другим
  агентом): проходы шли на образе неизвестного состава. Правило «стенд только по сигналу
  координатора» объявлено всем и в этом заходе соблюдено.
